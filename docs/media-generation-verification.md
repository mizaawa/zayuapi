# 图片与视频协议验证记录

日期：2026-10-12。目标版本：v0.2.144。

## 本地验证

- 视频工作台默认宽高比 1:1，分辨率默认自动；自动统一按 720p 发送，自动、480p、720p、1080p、2k、4k 六档均保留。不添加 SD 模型专属参数限制。
- 前端关键回归及使用日志测试共 422 项通过；桌面、390px、320px 浏览器检查通过，无页面脚本错误及横向溢出。
- 后端 service、handler、repository、middleware 单元测试通过。
- 后端 golangci-lint 检查通过，0 个问题；相关前端 ESLint 检查通过。
- 在独立 PostgreSQL 数据库中运行预扣费、原有统一计费账本和备份恢复集成测试。测试只替换测试环境启动方式，业务断言与仓库中的集成测试相同。
- 20 个并发请求共享 0.10 余额，每个预扣 0.03，只接受 3 个；重复并发退款后余额准确恢复。
- 图片和视频工作台均在任务创建时预扣，排队任务同样扣费；预扣后额度耗尽不会阻止已支付的任务执行，失败或尚未发送的任务取消后只退一次。
- 请求创建、预支付、支付完成或余额退回组成三条关联审计记录。一个任务仍只累计一次请求数及最终净费用；未完成支付的日志受到清理保护。
- 取消与发送争抢同一支付记录时，已退款任务不能再发送，已发送任务不能作为排队任务退款；退款后认证缓存及时刷新。
- 安全复现确认重复 JSON 模型、时长字段可让供应商读取后面的值，预扣读取前面的值。已增加入口校验，拒绝重复、转义后重复及关键字段大小写变体，multipart 仍支持多个参考图文件。
- 阶梯定价模型目录按当前密钥分组及平台隔离，包含只有渠道分辨率阶梯单价的模型，并继续遵守管理员自定义模型列表。
- 浏览器连接本地模拟 Sora 上游，选择仅配置渠道 720p 阶梯单价、未配置账号模型映射的模型。创建保持在工作台并清空提示词，实际发送 `size: "720x720"`；按 5 秒预扣 0.05，按实际上游 3 秒结算 0.03，日志显示三个阶段。此项为模拟协议和账务验证，不是真实供应商出片。
- 订阅出资的请求使用订阅额度，不因现金余额为负而错误拒绝。
- API 端到端测试中，8 个并发请求共享只能支付一个视频的密钥额度，只产生一个上游请求。额度耗尽后仍能查询自己的已创建任务；其他密钥不能读取。
- 模拟 Sora 与 968 上游验证了路径、请求字段、参考素材转换、视频按实际时长结算、失败退款、重复查询幂等和图片分辨率计费。
- 已确认但尚未完成入账的结算或退款可从数据库重新执行；没有确认结果的预扣不按记录年龄自动退款。
- 上游已接受请求后，任务号缺失或数据库绑定失败均保留预扣，避免将已受理的付费生成误退款；上游明确拒绝时正常退款。
- 旧备份恢复不会继承恢复前的预扣记录，账本结构不完整时整体回滚。
