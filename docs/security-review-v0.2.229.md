# v0.2.229 本地安全复核

基线：`v0.2.228`。检查对象是本仓库的代码、锁定依赖和本次生成的应用，而不是线上部署或第三方账号。

| 检查 | 观察结果 |
| --- | --- |
| 转发与收费一致性 | Responses、Chat Completions、Messages 转换及 raw 回退使用出站档位；WebSocket 按轮固定身份和价格。账号策略冲突时不降档，组或密钥失效时不继续转发。上游成本与用户扣款分别核算。 |
| 余额与历史记录 | 在独立 PostgreSQL、Redis 和真实网关上向本地模拟上游发出三笔请求。普通基价均为 0.004 美元，UltraFast ×6.25 扣 0.025，Fast ×2 扣 0.008，普通档扣 0.004，总额 0.037。调价后历史倍率不变。余额及订阅的重复结算、归档幂等键均有数据库回归用例。 |
| 数据隔离 | 用另一身份读取同一笔用户账单时被拒绝，列表中也没有别人的记录。使用记录只公开显示身份与结算字段，不含原始 API Key、登录密码或上游凭据。桌面、手机两种视图均验收。 |
| 密码与凭据 | 检查了密码哈希和比对、管理员首次引导以及部署脚本。移除旧 Antigravity OAuth 默认密钥及测试中的副本，已对完整待发布树检查残留。Gitleaks 候选项经逐类核对：测试样本、文档示例、SQL 列名和 Google 公开分发的安装型客户端常量。未扫描或上传本机生产数据。 |
| 依赖与回归 | pnpm 冻结安装、在线审计没有已知告警；升级 Go 工具链及受影响的模块后，Go 模块审计未报告已知漏洞。前端 343 个文件、2,947 个测试通过；Go 单元、PostgreSQL/Redis 集成、嵌入前端和部署测试通过。 |

**边界与部署事项**

- 上游是本地模拟服务。真实供应商是否提供 UltraFast 取决于模型和账户权限；不能将此次验证理解为生产账号实测。9 个需要 Claude/Gemini 实际凭据的可选用例未运行。
- 只在本机 Windows 上实际启动服务。其他平台用交叉编译与二进制检查验证，不代表在对应操作系统上实机运行过。
- 不要把测试用的回环上游配置带入生产。按部署需求核对 `security.url_allowlist`、可以设置上游的管理员权限、受信代理及 JWT/TOTP 密钥管理；需要私有上游时只放行必要的地址。
- 删除当前版本中的固定值不会修改 Git 历史或使旧发行包失效。若曾将旧 Antigravity 值作为私密凭据使用，应在签发方更换或撤销，用环境变量注入新值。
- 上述结果是固定版本、依赖漏洞库及测试范围内的证据，不是对未知漏洞的保证。
